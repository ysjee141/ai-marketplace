# Research Analysis — 기획분석

## 목적

PRD의 **모든 가정과 미결정 항목에 근거를 붙이거나, 근거가 없음을 판정**한다.
근거 없는 기획 위에 쌓은 설계와 구현은 나중에 전부 버려진다.

## 원칙

- **PRD를 옹호하지 않는다.** 요구사항이 실현 불가능하거나 이미 다른 방식으로
  해결된 문제임을 발견하는 것이 이 단계의 최대 가치다.
- **출처 없는 주장을 산출하지 않는다.** `파일:라인`, URL, 또는 "근거 없음 — 추정"
  중 하나가 반드시 붙는다.
- **상충 정보는 병기한다.** 삭제하고 하나를 고르지 않는다. 양쪽과 판단 근거를 남긴다.
- **내부를 외부보다 먼저 본다.** 팀이 이미 내린 결정이 문서·코드에 남아 있는 경우가
  많다. 외부 리서치로 시작하면 그것을 놓치고 중복 결정을 만든다.

## 절차

### 1. 조사 항목 추출

PRD에서 다음을 목록화한다:

| 유형 | 추출 대상 |
|------|----------|
| 가정 | §가정 섹션의 모든 항목 |
| 미결정 | §미결정 섹션의 모든 항목 |
| 암묵 전제 | 본문 중 "기존 X를 활용한다", "이미 Y가 있다" 같은 서술 |
| 비기능 요구 | 수치 목표 (달성 가능성 확인 필요) |

### 2. 조사 순서

| 순서 | 대상 | 찾는 것 | 도구 |
|------|------|--------|------|
| 1 | `docs/`, ADR | 이미 내려진 결정, 폐기된 대안 | 파일 검색 |
| 2 | README, CONTRIBUTING, 설정 파일 | 프로젝트 관례·제약 | 파일 읽기 |
| 3 | 코드베이스 | 유사 기능의 기존 구현, 재사용 자산 | 패턴 검색 |
| 4 | git 히스토리 | 과거 시도와 되돌림 이력 | `git log`, `git log -S` |
| 5 | 외부 (웹) | 표준·규격, 선행 사례, 알려진 함정 | 웹 검색 |

**4번(git 히스토리)을 건너뛰지 않는다.** "예전에 시도했다가 되돌렸다"는 정보는
다른 어디에도 없고, 같은 실패를 반복하는 것을 막는다.

### 3. 판정

각 항목에 다음 중 하나를 부여한다:

| 판정 | 의미 | 후속 |
|------|------|------|
| `확인됨` | 근거가 있고 PRD 서술이 맞다 | 없음 |
| `반증됨` | 근거가 PRD 서술과 반대다 | **즉시 리더 보고.** PRD 수정 필요 |
| `재검토 필요` | 근거가 PRD를 부분적으로만 지지한다 | 계획 단계에서 다룰 항목으로 표시 |
| `근거 없음` | 조사했으나 판단 근거를 찾지 못했다 | 리스크로 등록 |

`근거 없음`과 `미조사`를 구분한다. 전자는 찾아봤으나 없는 것, 후자는 안 찾아본 것이다.
**미조사 항목은 반드시 명시한다.**

### 4. 신뢰도 표기

| 신뢰도 | 기준 |
|--------|------|
| 높음 | 코드·설정 파일에서 직접 확인. 1차 출처 |
| 중간 | 문서 기술. 간접 근거 |
| 낮음 | 추론. 오래된 정보. 출처 불명확 |

## 산출물 형식

`_workspace/{slug}/02_analysis/02_research-analyst_findings.md`
템플릿: `docs/template/analysis-research.md`

핵심은 판정 표다:

| # | PRD 항목 | 판정 | 근거 | 출처 | 신뢰도 |
|---|---------|------|------|------|--------|
| 1 | A-2 "기존 회원 DB 재사용" | 확인됨 | `users` 테이블 존재, 마이그레이션 이력 | `db/migrations/003_users.sql` | 높음 |
| 2 | 미결정-1 "OAuth는 다음 단계" | 재검토 필요 | OAuth 클라이언트 설정이 이미 존재 | `config/oauth.yaml:1-20` | 높음 |
| 3 | NFR-2 "일 10만 요청" | 근거 없음 | 현재 트래픽 데이터 접근 불가 | - | - |

추가로 포함할 것:

- **반증된 항목의 영향 분석** — PRD의 어느 부분이 수정되어야 하는가
- **재사용 가능 자산 목록** — 이미 존재하여 새로 만들 필요 없는 것
- **미조사 영역** — 조사하지 않은 것과 그 이유

## 웹 검색이 불가능할 때

1. 그 사실을 산출물 서두에 명시한다
2. 내부 근거만으로 분석한다
3. 외부 근거가 필요했던 항목을 "외부 확인 필요"로 표시한다
4. **추측으로 외부 사례를 지어내지 않는다.** 존재하지 않는 선행 사례를
   근거로 삼으면 이후 모든 판단이 오염된다

## 재실행 시

기존 findings를 읽고, 게이트 지적 사항에 해당하는 항목만 보강한다.
이미 `확인됨`인 항목은 재조사하지 않는다.

## 완료 판정

- [ ] PRD의 모든 가정·미결정 항목에 판정이 붙었다
- [ ] 모든 발견에 출처가 있다
- [ ] `반증됨` 항목이 있으면 즉시 보고되었다
- [ ] 미조사 영역이 명시되었다
- [ ] 재사용 가능 자산이 목록화되었다
