# 명확한 한국어 문장 지침 (보조 지침)

이 문서는 의미가 명확하고 가독성이 높은 한국어 문장을 쓰기 위한 보조 지침입니다. [`writing-guide.md`](./writing-guide.md)가 문서 구성과 문장 규칙의 주 기준이고, 이 문서는 LLM이 한국어를 쓸 때 자주 보이는 습관을 문장·구 단위에서 보완합니다. 두 지침이 충돌하면 writing-guide.md를 따릅니다.

각 조항에는 예시를 붙였습니다. 예시는 `[수정 전 → 수정 후]` 형식이며, 조항의 문구가 구체적으로 어떤 문장을 의도하는지 예시로 확인합니다. 이 지침을 요약해서 쓰면 예시가 빠져 의도를 놓치기 쉬우므로, 점검할 때는 전체를 그대로 읽습니다.

## 적용 범위

1. 이 지침은 한국어 문장을 명확하게 쓰라는 지시입니다. 외국어 문장이나 어휘를 한국어로 번역하거나 대체하라는 지시가 아닙니다.
2. 인용문, 코드, 코드 주석, 변수명, 커밋 메시지, 로그 문자열처럼 코드에 속하는 텍스트에는 적용하지 않습니다. 이런 텍스트는 프로젝트의 기존 관례를 따릅니다.
3. 고유 명사와 기술 용어는 통상적인 용례로 정착된 번역어나 음차가 있으면 그것을 쓰고, 없으면 원어를 유지합니다. writing-guide.md 2부의 표기 통일 규칙과 함께 적용합니다.

## 문장 단위

1. **의미가 있는 문장 성분을 생략하지 않습니다.** 읽는 이가 문장만 보고도 의미를 충분히 이해할 수 있어야 합니다. 특히 관형격 조사 "~의"를 필요 이상으로 쓰면 의미를 담은 성분이 빠지기 쉬우므로 유의합니다.
   - [그러면 경고가 붙습니다. → 그러면 이미 작업 중인 파일에도 경고 표지가 추가됩니다.]
   - [사본의 문구는 작업의 상황을 → 사본에 기재된 문구는 작업이 진행되는 상황을]
2. **문장은 서술어와 종결어미로 끝맺습니다.** 명사구, 부사구, 연결어미로 문장을 끝내지 않습니다. 이 조항은 제목과 목록 항목에는 강제하지 않습니다. 목록 항목의 형태는 writing-guide.md 2부의 "목록 항목의 형태를 맞춥니다" 규칙을 따릅니다.
   - [설정 파일을 수정한 뒤 재시작. → 설정 파일을 수정한 뒤 재시작합니다.]
   - [캐시를 비우고 나서, → 캐시를 비운 뒤 다시 조회합니다.]

## 구 단위

1. **조사와 어미를 생략하지 않습니다.** 부사, 보조사, 선어말어미, 보조 용언을 적극적으로 써서 어휘 사이의 관계를 드러냅니다.
   - [이 결정은 이후 중요 정책이 갈리는 자리. 컨텍스트 압축 전 신중 반영한다. → 이 결정은 이후 중요한 정책에 지속적으로 영향을 주기 때문에, 컨텍스트가 압축되기 전에 신중히 반영합니다.]
2. **맥락에 맞는 한자어를 골라 쓰고, 조사와 어미를 붙여 관계를 분명히 합니다.** 구체적인 의미를 담은 한자어와 자연스러운 통사 구조를 결합하면 의미가 풍부하고 명확해집니다. 다만 한자어를 조사 없이 겹겹이 이어 붙이지는 않습니다. writing-guide.md 2부의 "한자어를 겹겹이 쌓지 않습니다" 규칙과 함께 적용합니다.
   - [쓴 비용을 구하는 토큰 카운트 함수에 문제가 생기면 → 지출한 비용을 추론하는 토큰 카운트 함수에 오류가 발생하면] (상황에 맞는 어휘로 의미를 채웁니다)
   - [지출 비용 추론 용도의 토큰 카운트 함수의 오류 상황에서 → 지출한 비용을 추론하는 토큰 카운트 함수에 오류가 발생하면] (조사와 어미를 살려 관계를 드러냅니다)
3. **비유적 어휘로 일반 명사나 동사를 대체하지 않습니다.** 일반 어휘가 들어갈 자리에 비유를 쓰면 가독성이 떨어지고 의미가 변질되기 쉽습니다. 다만 일상적인 문어와 해당 분야에서 관용 표현으로 정착되어, 일반 어휘로 바꾸면 오히려 어색해지는 표현은 그대로 씁니다.
   - [분석의 흐름 → 분석의 방향성]
   - [코드로 박는 자리 → 코드에 명시하는 상황]
   - [요청을 받습니다 → 요청을 확인했습니다]
4. **엠대시(—)를 쓰지 않습니다.** 엠대시는 앞뒤 문장의 관계를 지나치게 함축합니다. 문맥과 형식에 따라 콜론, 접속사, 또는 문장 분리로 대체합니다.
   - [배포는 실패했다 — 환경 변수가 빠졌기 때문이다. → 환경 변수가 빠져서 배포가 실패했습니다.]
