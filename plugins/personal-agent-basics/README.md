# Personal Agent Basics

Claude Code와 Codex에서 함께 쓰는 기본 skill 모음입니다.

## 포함 항목

- `engineering-response`: 기술 작업의 원인·과정·결과를 명확히 정리하는 응답 skill
- `concise-engineering`: 결과를 먼저 제시하는 간결한 응답 skill
- `output-styles/concise-engineering.md`: Claude Code에서 선택할 수 있는 동일 목적의 output style

공통 skill 파일은 특정 제품의 명령어나 도구에 의존하지 않도록 작성합니다. 제품별 기능이 필요해지면 해당 플러그인 내부에 별도 adapter를 추가합니다.
